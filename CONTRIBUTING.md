# Contributing

Thanks for helping shape `rules_sbom`!

- Use Bazel `7.1.x` or newer; we target compatibility with the latest Bazel `7` line while preparing for `8.x`.
- Run `bazel build //...` before submitting changes to ensure the repository remains consistent.
- Keep documentation in `docs/` aligned with public Starlark APIs.
- Add or update examples when introducing new rule attributes or toolchains.
